## ASA-relevant

### [casantosmu/audiodeck](https://github.com/casantosmu/audiodeck) — **3**
Self-hostable web spectrogram analyzer (Go server, browser-side render)
aimed at sniffing out fake-lossless files via frequency-cutoff
artifacts. 109★, TS, created Sep 2025. Analysis itself is shallow, but
the "thin Go shim + client-side spectrogram" topology is a clean shape
to mimic if ASA grows a library-scan UI.

### [mhartzel/freelcs](https://github.com/mhartzel/freelcs) — **3**
Hotfolder-driven EBU R128 loudness-correction server (Python, Docker,
mono → 5.1, per-stream). 25★, repo started 2012 but still pushed in
2026. Old code, but the drop-in/processed-out pipeline shape and the
visual loudness-history output are a useful reference for ASA's
loudness stage UX.

## Harmonia-relevant

### [dogayuksel/webKeyFinder](https://github.com/dogayuksel/webKeyFinder) — **4**
libKeyFinder (C++) compiled to WASM via Emscripten, fed by an
AudioWorkletProcessor and Web Workers, wrapped in Preact. 35★, TS,
pushed Mar 2026. This is the cleanest current template for the
exact plumbing Harmonia would need to add audio→key: WASM DSP in a
worker, worklet pulling PCM, all in-browser.

### [brightlikethelight/music21-mcp-server](https://github.com/brightlikethelight/music21-mcp-server) — **3**
FastMCP server exposing 13 music21 tools — Roman numerals, cadence
detection, voice leading, harmonization, counterpoint — plus HTTP/CLI
mirrors for when MCP itself misbehaves. 22★, Python. Worth a look as
the "music theory through an LLM" surface, but read the author's own
"40-50% MCP production success rate" caveat before treating it as
load-bearing.

## Both

### [uisato/ableton-mcp-extended](https://github.com/uisato/ableton-mcp-extended) — **3**
Extended Ableton MCP with parallel TCP + UDP servers (UDP for
low-latency real-time control), ElevenLabs TTS for in-session
narration/voice samples, and a custom-controller framework. 203★,
Python. Same family as producer-pal / bschoepke's ableton-live-mcp;
the UDP path and the controller-extension scaffold are the
differentiators.
