## ASA-relevant

### [wavey-ai/mel-spec](https://github.com/wavey-ai/mel-spec) — **4**
Rust mel/STFT primitives aligned with Whisper/librosa/PyTorch, plus a
Sobel-edge-detection VAD that reuses the same mel tensor, and an 8-bit
TGA interchange format for shipping quantized mel spectrograms between
processes. 89★, Rust, pushed within the window. The TGA mel-image
interchange and WASM path (used by their Hush in-browser Whisper) are
directly applicable if ASA wants a wire format for mel data.

### [undef13/splifft](https://github.com/undef13/splifft) — **3**
Lightweight Python separation/transcription CLI: BS-Roformer (incl.
HyperACE/Large Inst variants), Mel-Roformer, MDX23C TFC-TDF v3, plus
`beat this!` (no-DBN beat tracking), PESTO pitch, basic-pitch
polyphonic. 110+ community models in a registry. 40★, pre-alpha, Jun
2025. Clean "swap separation backend" abstraction if ASA grows a
pre-stage; modular dataclass/Pydantic design over zfturbo's MSST.

### [Boof2015/astra](https://github.com/Boof2015/astra) — **3**
Electron + native C++ DSP audiophile player: 10-band parametric EQ
with live frequency-response, seven realtime visualizers (scope,
spectrum, vectorscope, …) on a customizable rack, gapless bit-perfect
output (WASAPI Exclusive / CoreAudio HAL / ALSA hw), Dolby Atmos
decode. 247★, TypeScript, created Jan 2026. The decoupled
analysis-path-vs-output-path architecture and the visualizer rack UX
are both directly cribbable for ASA.

## Harmonia-relevant

### [markwilkins/midi-chord-reader](https://github.com/markwilkins/midi-chord-reader) — **3**
JUCE/C++ DAW plugin that names chords from a MIDI track during
playback — normalises to a single octave while preserving bass note,
generates slash inversions (`Am/C`), filters 2nd/4th/6th passing tones,
uses the lowest three notes for quality. 22★. Tiny but a useful
reference heuristic if Harmonia ever wants "given these MIDI notes,
name the chord" outside its Tonal.js path.

### [Natooz/MidiTok](https://github.com/Natooz/MidiTok) — **3**
The canonical MIDI/abc tokenizer library: REMI, REMI+, MIDI-Like, TSD,
Structured, CPWord, Octuple, MuMIDI, MMM, PerTok; BPE/Unigram/WordPiece
training; HF Hub integration; Symusic-backed I/O. 870★, Python.
Well-known to anyone in symbolic music gen — include only because it's
the obvious dependency if Harmonia ever ingests/produces token
sequences. Skip if you already know it.

## Both / Tangential but interesting

### [dreamrec/LivePilot](https://github.com/dreamrec/LivePilot) — **4**
The most ambitious Ableton-MCP so far: 465 tools / 56 domains, a
5,264-device atlas, an optional M4L spectral-perception bridge (9-band
FFT, RMS/peak, Krumhansl-Schmuckler key, pitch, FluCoMa
mel/chroma/onset), VST/AU/AAX corpus discovery, and 12 "creative
engines" with before/after measurement. 21★, Python, Mar 2026. Sits
across both projects: the in-DAW analysis bridge is ASA-adjacent and
the Krumhansl-Schmuckler key + chroma path is Harmonia-adjacent.

### [bschoepke/ableton-live-mcp](https://github.com/bschoepke/ableton-live-mcp) — **3**
General-purpose Ableton MCP whose bet is "let the agent `eval`
arbitrary Python inside Ableton, with a few hot-path tools for
latency/reliability." Latency-tuned via Codex's `/goal`. 184★, Python,
created May 2026. Different philosophy from producer-pal (curated
tools); worth a read for the trade-off, but the third Ableton-MCP on
the seen list — diminishing returns.

### [phones24/ep133-export-to-daw](https://github.com/phones24/ep133-export-to-daw) — **3**
PWA that reads `.pak` backups (or talks live over WebMIDI) from
Teenage Engineering EP-133/EP-1320/EP-40 and exports Ableton Live
projects, DAWproject archives, REAPER projects, and MIDI — including
sample envelopes and stretch modes. 88★, TypeScript. Hardware-bound
but the WebMIDI → DAWproject pipeline is reusable plumbing if
Harmonia ever round-trips to a DAW.

### [gluon/Void-LinkAudio](https://github.com/gluon/Void-LinkAudio) — **3**
Same author as the already-logged `gluon/ofxAbletonLinkAudio` (which is
the openFrameworks sub-addon). This is the umbrella project:
sample-accurate beat-synced audio over LAN between Max, TouchDesigner,
VCV Rack, openFrameworks, and Live 12.4+; v0.3 adds Linux ARM64/x86_64
for VCV and Pure Data. 40★, Apr 2026. Worth swapping the seen entry
for if you only want the top-level project.

### [Conceptual-Machines/magda-core](https://github.com/Conceptual-Machines/magda-core) — **3**
AI-first DAW on C++20/JUCE/Tracktion Engine: natural-language chat
generates a custom DSL that mutates the session, hybrid audio+MIDI
tracks, 16 LFOs + 16 macros per device, nestable parallel racks,
juce-llm + llama.cpp for local inference. 124★, C++, Jan 2026.
Tangential to both ASA and Harmonia but the cleanest "AI as a
first-class DAW citizen" reference around — interesting precedent if
either project ever sprouts an agentic surface.

### [andremichelle/openDAW](https://github.com/andremichelle/openDAW) — **3**
1.6k★ web-based DAW, AGPL, deliberately framework-light (Tauri/PWA
wrapping wanted). No MIR or analysis surface — pure composition — but
the web-audio engineering and the project's "no SignUp / no Tracking"
ethos are useful references for ASA/Harmonia as browser-first tools.
Created Feb 2025.
